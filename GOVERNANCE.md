# Governance & Ownership

StudentHunter is an open source project developed as part of a student initiative. The goal is to create a public, reusable platform that helps students find internships and first jobs while giving employers better access to young talent.

## Ownership

- The project is maintained by the StudentHunter team (students of the relevant course/program).
- The source code is hosted at: https://github.com/sl-ars/StudentHunter
- The project is licensed under an open source license (see `LICENSE`).

## Roles

- **Maintainers**: Have write access to the repository, review and merge pull requests, manage releases, and make high-level technical decisions.
- **Contributors**: Anyone who submits issues, suggestions, or pull requests.
- **Users**: Students, employers, and institutions who deploy or consume StudentHunter.

A current list of maintainers can be found in the GitHub repository (e.g., via the “Insights → Contributors” view or in the repository description).

## Decision-Making

- Technical discussions and feature proposals should happen in GitHub Issues or Pull Requests.
- Maintainers aim to reach consensus through open discussion.
- In case of disagreement, maintainers make the final decision, based on:
  - Alignment with the project’s goals.
  - Impact on users (especially students).
  - Long-term maintainability.

## Roadmap

The roadmap is maintained in the repository, using:

- Issues labeled as `enhancement` or `feature`.
- Milestones for grouping features by release or phase (e.g., MVP, Phase 2).

Community feedback and contributions are welcome and can influence the roadmap.

## Transparency

- Changes are proposed and discussed publicly via pull requests.
- Governance documents (this file, Code of Conduct, Privacy, etc.) are versioned in the repository.
- Any significant policy changes will be documented through a PR that the community can review.
