# Code of Conduct

StudentHunter is a community-driven project that aims to support students from diverse backgrounds in finding opportunities. We want this project to be a safe, inclusive, and welcoming space for everyone.

## Our Values

- Be respectful and kind in all interactions.
- No harassment, hate speech, or personal attacks.
- No discrimination based on gender, gender identity, sexual orientation, disability, physical appearance, body size, race, ethnicity, nationality, religion, or any other protected characteristic.
- Assume good intent, but also be open to feedback and correction.

## Expected Behavior

- Use inclusive and respectful language.
- Welcome new contributors and help them learn.
- Focus on the technical issues rather than personal differences.
- Give constructive feedback and be open to receiving it.

## Unacceptable Behavior

- Harassment of any kind (verbal, written, or visual).
- Threats of violence or encouraging self-harm.
- Publishing others’ private information without explicit permission.
- Any behavior that makes others feel unsafe or unwelcome.

## Reporting Issues

If you experience or witness behavior that violates this Code of Conduct:

- Please contact the maintainers at: **studenthunter.team@gmail.com**.
- Include as much detail as you can (links, screenshots, timestamps).

All reports will be handled confidentially. The maintainers will review the situation and may take appropriate action, including warnings, temporary bans, or permanent bans from participation.

## Scope

This Code of Conduct applies to:

- The main repository and its issues, pull requests, and discussions.
- Any communication channels associated with the project (e.g., chats, forums, mailing lists).
- Any public events or meetings organized under the StudentHunter name.

By contributing to StudentHunter, you agree to follow this Code of Conduct.
